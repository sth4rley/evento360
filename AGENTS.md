# Regras do projeto

- Projeto escrito em TypeScript.
- Frontend React + Vite + Tailwind CSS.
- Backend Node.js + Express.
- Banco PostgreSQL usando Prisma.
- Backend e a autoridade das regras de negocio.
- Nunca confiar no frontend para autorizacao.
- Nunca armazenar secrets no codigo.
- Rotas publicas e administrativas devem permanecer separadas.
- Todo evento pertence a um Organizer.
- Toda Registration pertence a um Event.
- Preservar funcionalidades ja implementadas.
- Evitar alterar arquitetura sem necessidade.
- Novas funcionalidades devem possuir testes.
- Antes de considerar uma TASK concluida, executar build e testes.
- Nao implementar funcionalidades de TASKs futuras sem solicitacao.
